========================================================================
1. Ordinary execution: effects are immediate and persistent
========================================================================
No speculation: the write and the deletion are visible at once and cannot be withdrawn.
$ echo ORDINARY_NOTE > /demo/note.txt
$ cat /demo/note.txt
    ORDINARY_NOTE
  [PASS] ordinary write visible immediately
$ rm /demo/note.txt
$ cat /demo/note.txt
    cat: cannot open /demo/note.txt
  [PASS] ordinary deletion is immediate; nothing can undo it

========================================================================
3. Abort: original state preserved, pending output suppressed
========================================================================
The handout's case: a speculative child removes a, writes hi into b and prints, then aborts.
$ specrun abort rm,/demo/a.txt echo,hi,into,/demo/b.txt echo,ABORT_SECRET_LINE
    SPECRUN: aborted: private changes and held output discarded
  [PASS] speculation aborted
$ cat /demo/a.txt
    original a
  [PASS] a.txt still exists with its original contents
$ cat /demo/b.txt
    cat: cannot open /demo/b.txt
  [PASS] b.txt was never created publicly

5. Internal pipe keeps working inside a speculation
========================================================================
cat and wc are both members; the pipe between them is internal, so bytes flow at once (no deadlock); only the final console output is held until commit.
$ cat /demo/report.txt | wc
    1 7 46
$ specrun commit cat,/demo/report.txt,pipe,wc
    [review 4 BEGIN]
    [speculation 4] specrun requested review
    Kernel change report (saved original -> private):

    Changed blocks: 0. Every changed block listed; byte previews limited to 24 bytes.
    Held console bytes: 8. Held external-pipe storage bytes (includes record headers): 0. Payloads remain hidden until durable commit.
    [approval 4] commit? [y/n] y
    1 7 46
    SPECRUN: committed: changes published; held output released above
  [PASS] speculative pipeline gives the same counts as the ordinary pipeline

6c. Outside write to a privately copied block is refused (D20)
========================================================================
A speculation overwrites a2.txt and pauses; an ordinary write to the same block is refused (the shell's echo ignores the error), and the speculation then commits.
$ echo OUTSIDER > /demo/a2.txt
$ cat /demo/a2.txt
    public version
  [PASS] outside write had no effect while the copy exists
$ cat /demo/a2.txt
    cat zomb/ie!
    demo/a2.txt; echo DONE8d34b5fdab
    SPEC_A2
    ersion
  [PASS] speculation committed its version

7. What the barrier does NOT do
========================================================================
